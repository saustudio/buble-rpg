//#region SPECIFICATION

//================= КОМПОНЕНТЫ =====================//
//Компоненты = только данные (структуры)
//Компоненты НЕ содержат логику
//Компоненты НЕ содержат методов (кроме геттеров/сеттеров)
//Компоненты плоские (не содержат вложенных объектов с логикой)

//================= СУЩНОСТИ =====================//
//Сущности = только идентификаторы (EntityId)
//Сущности создаются через фабрики (EntityFactory)
//У одной сущности НЕ может быть более одного компонента одного типа

//================= СИСТЕМЫ =====================//
//Системы = только логика (функции)
//Системы НЕ хранят состояние (stateless)
//Системы НЕ хранят данные что можно разместить в компонентах
//Системы независимы — нет прямых вызовов между системами
//Системы общаются только через компоненты в World
//Сломанная система НЕ ломает другие системы
//Каждая система отвечает за ОДНУ задачу (SRP)
//Одна причина для изменения у системы
//Название системы отражает её задачу
//Системы группируются по МЕХАНИКАМ, а не по типам сущностей (что делает , а не кто)
//Система должна знать о КОМПОНЕНТАХ, а не о ТИПАХ сущностей
//Системы обрабатывают данные, а не управляют ими


//================= ФИЧИ/МОДУЛИ =====================//
//Фича = набор систем + сущностей + компонентов
//Фичи объединены одной общей логикой
//Фичи можно включать/отключать в любой момент
//Отключение фичи НЕ ломает другую логику
//Добавление новой фичи НЕ требует изменений в существующих системах
//Фичи независимы друг от друга
//Фичи должны называться по МЕХАНИКЕ, а не по реализации
